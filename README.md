# Home Care

## Descrição

Home Care é um projeto dedicado a soluções inovadoras para cuidados de saúde em casa.

## Objetivo

Fornecer ferramentas e recursos para melhorar a qualidade de vida dos pacientes sob cuidado domiciliar.

## Funcionalidades

- Monitoramento de saúde
- - Agendamento de consultas
  - - Histórico médico digitalizado
    - - Comunicação com profissionais de saúde
